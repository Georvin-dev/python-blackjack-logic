# Python Blackjack Game Logic

A command-line interface (CLI) implementation of the classic Blackjack card game, developed in Python. This project highlights the use of fundamental programming concepts to manage game flow, rules, and user interaction.

## Key Technical Features
*   **Game Loop:** Implements a continuous while-loop to manage game rounds.
*   **Rule Validation:** Uses conditional logic to determine card values, hand totals, and winning/losing conditions (including "Bust" and "Blackjack").
*   **Modular Design:** Structured using Python functions for card dealing, turn management, and score calculation.
*   **Data Structures:** Utilizes lists to represent the deck of cards and player/dealer hands.

## Programming Concepts Applied
*   Loops (`while`, `for`)
*   Conditionals (`if`, `elif`, `else`)
*   Functions and parameter passing
*   Input handling and output formatting

## How to Run
1.  Ensure you have Python installed.
2.  Download or clone this repository.
3.  Run the script from your terminal:
    ```bash
    juego_blackjack.py
    ```
